# Scientific Calculator 🧮

## About

A menu-driven scientific calculator built with Python that performs basic arithmetic and scientific calculations.
 This project was created to practise Python functions, loops, conditional statements, exception handling, and the `math` module.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Exponentiation and square root
- Factorial
- Natural and base-10 logarithms
- Trigonometric functions: sine, cosine, and tangent
- Basic input validation and error handling

## Technologies

- Python 3
- Built-in `math` module


## Concepts Practised

- Functions and code reusability
- Loops and conditional statements
- Exception handling (`try` and `except`)
- User input and type conversion
- Mathematical operations and input validation
